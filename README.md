# 🌟 About Project

S52 News Portal is a modern responsive news website developed using **HTML, CSS, JavaScript and Firebase Authentication**.

The project provides secure login functionality along with an elegant UI inspired by professional news websites.

It includes:

- 🔐 Firebase Authentication
- 📰 Responsive News Layout
- 📱 Mobile Friendly Design
- 🎨 Modern UI
- ⚡ Fast Loading
- 🔒 Protected Pages
- 📢 Breaking News Ticker
- 👤 User Profile Badge
- 🌙 Smooth Animations
- 💻 Clean Code Structure

# 🔥 Firebase Setup

Create a Firebase Project

Enable

- Authentication
- Email/Password Login

Replace

```javascript
const firebaseConfig = {
 apiKey:"",
 authDomain:"",
 projectId:"",
 storageBucket:"",
 messagingSenderId:"",
 appId:""
}
```

with your own Firebase credentials.
